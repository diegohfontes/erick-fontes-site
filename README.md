# erickfontes.com.br

Site de pré-lançamento do Erick Fontes (músico, [@erickfontesmusico](https://www.instagram.com/erickfontesmusico/)). HTML/CSS/JS puro, sem build step, publicado via GitHub Pages.

## Fonte de verdade

O sistema visual e de voz vem do DNA Criativo da marca:
`Clients/Erick Fontes/Erick Fontes DOC/DNA/resultado/DNA.md` (MYOS)

O brief de conteúdo/estrutura está em:
`Clients/Erick Fontes/Erick Fontes PROJECTS/2609 Erick Fontes - Site/doc/` (MYOS)

## Estrutura

- `index.html` — página única
- `styles.css` — tokens de design derivados do DNA (paleta, tipografia, espaçamento)
- `script.js` — contagem regressiva do lançamento (fica em "Em breve" até a data real ser confirmada)
- `assets/` — fotos reais (hero e secundária), otimizadas via `sips`
- `CNAME` — domínio customizado do GitHub Pages
